이전 단계의 중요한 검사가 통과한 후 다음 작업을 진행했다. 외부 OAuth 미설정을 합성 검증으로 통과 처리하지 않았다.

## 실행한 검사

- `npm run check`: PGlite 기본 실행은 40개 통과·별도 PostgreSQL 연결 시험 1개 생략이다. 실제 PostgreSQL URL을 지정하면 41개 모두 통과한다. 명세·린트·타입도 통과했다.
- `PLANNER_TEST_DATABASE_URL=... npm run check`: Docker PostgreSQL 18의 서로 다른 연결에서 동시 수정 200/412, 처리 중 키의 409·Retry-After, 같은 키의 재생·만료, 실패한 활동 쓰기의 전체 롤백을 확인했다.
- API 응답은 구현과 별개인 OpenAPI 0.4.0의 JSON Schema를 Ajv 2020으로 검증한다. 선언되지 않은 상태·누락 필드·추가 필드·형식·ETag·no-store 오류를 검사한다. 구조 검사 스크립트는 계속 구조 확인만 담당한다.
- `npm run test:e2e:product`: 실제 PostgreSQL과 서비스 자체 세션으로 PC·360px 모바일 16개 통과. 합성 계정·세션은 테스트가 DB에 준비하며 앱에는 테스트용 로그인 경로가 없다.
- `npm run build`: 통과. 안내 화면·기본 API·접근성 회귀 10개도 통과했다. GitHub CI는 원격 실행 후 별도 기록한다.

## 중요한 실패와 조치

1. 성공 응답 유실: DB 커밋 후 응답을 의도적으로 차단했다. 화면은 입력·원래 요청 키를 보존하고 재시도 성공 시 원본 한 개만 표시한다. 24시간 이후에는 요청을 보내지 않는다.
2. 동시 수정: 오래된 버전은 412로 거부한다. 최신 항목과 내 변경을 비교한 뒤 사용자 선택으로 새 버전·새 키를 사용한다.
3. 저장 중 오류: 테스트 DB 트리거로 활동 INSERT를 실패시켰다. 과제·활동·키 모두 롤백됐고 같은 키로 정상 재시도했다. 원문 SQL 오류는 응답에 없다.
4. 계정 변경: 브라우저의 실제 세션을 다른 합성 사용자로 전환했다. 기존 목록·입력·보류 요청을 지우고 새 계정 화면으로 이동했다.
5. 접근성: 안내 문구의 색 대비와 로고의 읽기 이름 오류를 발견해 수정했다. 자동 WCAG A/AA 검사를 통과했으며 수동 스크린리더 적합성 전체를 인증한 것은 아니다.
6. 테스트 실행: Next의 기본 알림 영역과 테스트 탐색자가 충돌한 문제와 Playwright 작업자 간 DB 풀 수명 문제를 수정했다. 제품 동작과 테스트 인프라 결함을 구분했다.
7. 초기 목록 로딩 완료가 최신 저장 실패 안내를 덮어쓰는 경합을 발견했다. 상태 갱신 세대를 구분해 오래된 작업의 안내를 무시하고, 실제 실패 안내 검증을 유지한 채 PC·모바일 전체 16개를 다시 통과했다.

기존 GitHub CI는 PR #4에서 통과했다. 실제 PostgreSQL·제품 E2E를 추가한 설정안은 docs/ci/planner-verification.yml에 있으며, 연결 앱의 workflow 쓰기 권한 403과 잠긴 Mac으로 아직 실행 경로에 적용하지 못했다. 기존 원격 검사와 로컬 실제 DB·제품 브라우저 검증을 구분한다.

## 구현 제약과 남은 조건

- 실제 Google OAuth 클라이언트·동의 화면·테스트 사용자와 가입 대상 D-01이 필요하다. 신규 가입은 기본 차단이다.
- 운영 호스팅·도메인·비밀 관리·HTTPS·백업 주기·관측·부하 기준은 미확정이다. 이 기록은 배포 또는 수용 승인이 아니다.
- 자동 접근성 검사는 보조 증거다. 수동 키보드·스크린리더·장애 대응의 출시 검토는 별도다.
- 테스트 DB는 loopback의 별도 이름만 허용한다. 실제 사용자 데이터를 쓰지 않았다. Docker는 설치된 엔진을 기동해 일회용 컨테이너로 실행했다.
- 과제 이외의 일정·메모·가치·목표·회고 전체 요구는 구현 완료로 계산하지 않는다.

만료 정리 명령은 실제 테스트 DB에서 만료 요청·OAuth state·세션 각각 1개만 삭제했고 사용자 2명·과제 1개·유효 요청 기록 1개는 보존했다. 목록 로딩 도중 시간대가 변경되는 경쟁 조건도 PC·모바일에서 재현해 이전 기준 결과를 버리는 것을 확인했다.
