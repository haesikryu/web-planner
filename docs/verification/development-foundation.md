## 기반 검사와 제품 검사의 구분

기반 E2E는 로그인 버튼이 아직 비활성화돼 있고 준비 중임을 표시하는지 확인한다. 로그인 성공 테스트가 아니다. `/api/health`는 liveness만 표시하고 DB·인증 readiness를 주장하지 않는다.

단위 테스트는 합성 환경변수만 사용한다. 실제 비밀값은 작성·출력·공개하지 않았다. 테스트에서 잘못된 서버 설정은 실행을 거부하고 오류에 항목명만 포함하는지 확인했다.

CI는 잠금 파일 설치 후 같은 검사와 프로덕션 빌드, Chromium PC·모바일 검사를 수행하도록 정의했다. 구현되지 않은 API·인증·데이터 마이그레이션의 검수 결과를 통과로 기록하지 않는다.

[원격 CI 검증 증적](https://github.com/haesikryu/web-planner/actions/runs/42322612237)

CLI OAuth 인증에 workflow scope가 없어 첫 CI 업로드가 거부됐다. 기존 사용자 로그인 브라우저에서 검토 브랜치에 CI 파일을 등록했고, 인증 권한 범위를 확대하지 않았다. 앱과 CI는 [Draft PR #2](https://github.com/haesikryu/web-planner/pull/2)에서 검토한다. 명세 PR #1은 아직 별도로 열려 있으며 자동 병합하지 않았다.
