# 요구 정합성과 검수 보완

검토일: 2026-11-10 · CR-0003 · 요구 기준 v0.2 · 기능 명세 0.10

## 결과와 범위

기존 기준 86개를 평가한 CR-0002의 완료·통과는 16개(18.6%)였다. 최신 사용자 요청 7개에 고유 ID를 추가하고 대체된 FR-04-04를 원문 보존 폐기하여 등록 93개·유효 92개로 정리했다. FR-04-01·05는 변경된 하루 계획 기준을 기존 제품 증거와 대조하고, FR-05-02·NFR-02는 부족했던 직접 검증을 추가했다.

유효 요구의 구현 상태는 완료 27·개발중 21·검증중 1·미착수 43이다. 연결된 유효 검수기준은 통과 27·진행중 22·미실행 43이다. 두 비율은 현재 27/92=29.3%이며 공수 진척률이 아니다. 폐기 요구는 구현 보류·검수 미실행으로 보존하고 두 집계에서 제외한다. 요구 승인·사용자 인수·배포 승인을 대신하지 않는다.

## FR-05-02 마감일 독립성

`tests/unit/product-api.test.ts`의 두 회귀 사례는 기존 non-null 마감일 fixture를 사용한다. 실행일을 마감 이후로 변경하고 해제한 뒤 마감 이전으로 재배정한다. PATCH 응답·ETag·GET·목록·저장 DB에서 마감일 불변을 확인한다. 과거 요청 재생이 최신 원본을 되돌리지 않는지, 5개 한도와 오래된 버전으로 거절될 때 원본·활동·요청 키가 보존되는지도 검사한다. 실제 Route Handler의 Request/Response와 OpenAPI 계약을 검증하며 이번 전체 실행은 PGlite 대신 실제 PostgreSQL을 지정했다.

현재 API에 마감일 입력을 추가한 것은 아니다. 마감일 신규 입력·수정과 실행 대상/마감 대상 표시는 FR-05-01·FR-04-02에 남아 있다.

## NFR-02 키보드 핵심 흐름

`tests/e2e/planner.spec.ts`의 `keyboard-only daily workflow reaches inputs, ordering, status, calendar and saved records`는 실제 Tab·Shift+Tab으로 초점을 이동하고 키 입력으로 동작한다. DOM은 현재 초점·스타일을 읽는 데만 사용한다. 직접 focus·fill·click·selectOption으로 탐색을 생략하지 않는다.

201자 제목의 오류 안내 후 유효한 두 할 일을 입력하고, 순서 이동·취소, 완료·미룸·Escape 복귀, 달력 날짜 선택, 06:00/23:30 일정과 여러 줄 자유글 저장, 날짜 왕복·새로고침 후 서버 저장을 확인했다. `:focus-visible`, 불투명한 outline과 양수 두께, 초점 대상의 화면 내 표시를 검사하며 기존 axe WCAG A/AA 검사도 전체 실행에 포함한다.

macOS headless Chromium의 native select 팝업은 키 주입으로 선택값이 변경되지 않았다. 자동 연속 시험은 화면에 있는 다음 시간대 버튼을 Tab→Enter로 조작하며 9페이지와 마지막 칸 접근을 그대로 확인한다. 별도 CUA 실제 브라우저에서는 첫 입력까지 Tab으로 이동한 뒤 3px 초록 초점 테두리를 육안 확인했고, 일정 select에서 Space→End→Return으로 22:00~24:00과 23:30 입력을 표시했다. 이 근거는 실제 Google·스크린리더·모든 브라우저/실기기의 검증을 뜻하지 않는다.

## 중단 원인과 재실행

첫 제품 전체 실행은 52개 통과·4개 실패·4개 미실행으로 10분 상한에 종료되어 성공 증거에서 제외했다. macOS 기록의 22:05:54 화면 종료와 22:06:32~22:12:55 절전(383초)이 PC 준비/포인터 지연 및 모바일 trace의 383,340ms 입력 정지·381,364ms 로딩 지연과 일치했다. 초기 실패 자료와 로그를 비공개 로컬 작업 폴더에 보존했다.

코드·검사 조건·시간 제한을 바꾸지 않고 검증 명령 동안만 `caffeinate -diu`로 절전을 방지했다. 실패한 4종 시나리오를 PC·모바일에서 8/8 통과한 뒤, 제품 전체를 재실행하여 60/60·exit 0을 확인했다. 전원 설정을 영구 변경하지 않았고 사용자 DB나 실제 데모 자료를 테스트 fixture로 사용하지 않았다.
