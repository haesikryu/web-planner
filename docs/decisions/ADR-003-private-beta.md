# 본인 전용 비공개 베타

상태: 사용자 확정 (2026-11-07), 로컬 구현·회귀 검증 통과, 실제 OAuth 대기

사용자는 D-01 초기 서비스 이용 대상을 본인만으로 확정했다. 공개 소스 저장소와 서비스 접근 범위는 별개다. 실제 허용 이메일은 공개 문서에 기록하지 않고 `AUTH_ALLOWED_EMAILS` 서버 환경 변수에 저장한다.

Google ID 토큰의 서명·issuer·audience·nonce·만료·email_verified 검증 후 이메일을 명시적 허용 목록과 대조한다. 대소문자와 앞뒤 공백만 정규화한다. 점·더하기 별칭을 확장하지 않으며 와일드카드를 허용하지 않는다. 목록이 비었거나 잘못되면 인증 설정을 거부한다. 이메일은 접근 정책이며 기존 issuer/sub 계정 식별·병합 정책을 변경하지 않는다.

기존 세션도 매 제품 요청에서 현재 허용 목록을 확인하고, 제외된 계정의 세션을 폐기한다. 환경 변수 변경 후 서버 프로세스를 재시작한다. 최초 본인 가입 시에만 허용 목록을 설정한 상태로 `AUTH_ALLOW_SIGN_UP=true`를 사용한다. 이 플래그를 켜도 목록 밖 계정은 로그인·가입할 수 없다.

검증: 실제 PostgreSQL 포함 단위·계약·통합 47개, 제품 브라우저 16개, 기본 브라우저 10개 통과. 목록 누락·와일드카드·별칭·미허용 서명 토큰·기존 세션 철회를 확인했다. 실제 Google 제공자 및 호스팅 검증은 미완료다.
