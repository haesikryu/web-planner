# 첫 기능 작업과 검증 계획

T-001·T-002 완료 후 T-004~T-009의 첫 기능 범위를 구현·검증했다. T-003은 실제 Google OAuth 검증이 남아 있다. T-010은 계약·실제 PostgreSQL·PC/모바일 자동 검사 통과이며 수동 보조기술·실제 공급자·운영 검수는 별도다. T-011은 베타 진입 조건과 정리 명령을 준비했고 외부 설정을 기다린다.

| 작업 ID | 내용 | 선행 작업 | 완료 기준 | 검증 ID |
|---|---|---|---|---|
| T-001 | 실행 기술과 인증 라이브러리 선정 | 없음 | 버전·선정 근거·개발 실행 방식 기록 | 기술 검토 |
| T-002 | 프로젝트와 테스트·CI 기반 | T-001 | 로컬 실행, 타입·정적 검사, 격리 테스트 실행 | 기반 검사 |
| T-003 | Google 로그인·세션·로그아웃 | T-002 | 검증된 identity 연결, 쿠키·CSRF·계정 전환 처리 | V-06, V-08 |
| T-004 | 사용자·과제·활동·요청 키 스키마 | T-002 | 제약·마이그레이션·테스트 DB·복구 확인 | V-03, V-07 |
| T-005 | 제목과 날짜 공통 모듈 | T-002 | 코드 포인트·IANA·DST 경계 검증 | V-02, V-10 |
| T-006 | 생성·조회·페이지 처리 API | T-003, T-004, T-005 | 계약 응답, owner 필터, 키 재생 | V-01, V-03, V-06, V-07 |
| T-007 | 수정·완료·완료취소 API | T-006 | If-Match, 활동 원자성, 중복 방지 | V-04, V-09, V-11 |
| T-008 | 빠른 입력과 입력함 | T-006 | 저장 확인·실패 복구・정리 상태 분리 | V-01, V-02, V-05 |
| T-009 | 오늘 화면과 충돌 복구 | T-007, T-008 | 날짜별 표시·완료 취소·최신 데이터 재조회 | V-04, V-09, V-11 |
| T-010 | 계약·통합·E2E와 접근성 | T-003~T-009 | 핵심 시나리오 통과와 증적 연결 | V-01~V-11 |
| T-011 | 베타 환경·관측·복원 | T-010 | OAuth 설정·가입 범위·배포·복원 검증 | 운영 검증 |

T-001과 독립적인 명세 검토는 계속할 수 있다. 외부 OAuth 설정이 없으면 실제 Google 통합 검증을 통과로 처리하지 않는다. 모형 인증은 운영에서 비활성화한다.

## T-003·T-004 현재 증거

인증 초기 증거는 [기존 기록](../../docs/verification/auth-data-foundation.md)에 보존한다. 이후 [과제 흐름 검증](../../docs/verification/planner-core.md)에서 PostgreSQL 18 서버·pg_dump/pg_restore·미저장 입력의 계정 전환까지 검증했다. 각 작업은 선행의 중요한 검사를 통과한 뒤 진행했다. 제품 전체 요구·승인·배포 완료로 확대 해석하지 않는다.
