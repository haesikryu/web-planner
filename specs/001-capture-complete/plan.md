# 첫 기능 구현 설계

상태: 설계 초안 · 2026-11-06

## 구조

브라우저 → 동일 출처의 웹·API 서버 → 관계형 저장소의 단일 서비스로 시작한다. 인증·과제·날짜·조회·활동 모듈을 내부 경계로 구분한다. Google 인증은 서버 측 검증 라이브러리 어댑터로 감싼다. 첫 기능에 마이크로서비스나 별도 메시지 브로커를 도입하지 않는다.

실행 기술은 ADR-002에 따라 Next.js·React·TypeScript, Better Auth, PostgreSQL·Drizzle로 선정했다. 기본 앱·타입·린트·단위·브라우저 검증을 구성했다. 선택 기준은 계약 검증, 트랜잭션·유일 제약, Google 지원, 시간대 처리, 테스트 격리, 배포·복원 용이성이다. 운영 호스팅은 미선정이며 유료 서비스나 운영 환경을 생성하지 않는다.

## 계약

기계 판독 계약은 `contracts/openapi.json`이다. OpenAPI 3.1.1을 호환 기준으로 사용하며 최신 버전이라는 주장은 하지 않는다.

| API | 역할 |
|---|---|
| GET /api/session | 로그인 사용자·계정 시간대·서버 날짜·CSRF 토큰 확인 |
| POST /api/logout | 세션 종료 |
| PATCH /api/settings | 계정 시간대 명시적 변경 |
| GET /api/tasks | 입력함·선택 날짜·이전 미완료·완료일 조회 |
| POST /api/tasks | 과제 생성 |
| GET /api/tasks/{taskId} | 원본과 ETag 조회 |
| PATCH /api/tasks/{taskId} | 실행일·정리 여부·완료·완료 취소 |

Google 시작·콜백 경로는 인증 라이브러리가 담당하며 제품 데이터 API 계약과 분리한다. 쓰기 API의 JSON Content-Type, Origin·CSRF 검사, 소유권 검사, 필수 헤더, 요청 키 재생 규칙을 구현한다. 사용자·공급자 인증정보를 요청 본문으로 대신 받아 로그인시키지 않는다.

오류는 code·message·requestId를 갖고 개인정보 없는 설명을 제공한다. 401 미인증, 403 CSRF/Origin 오류, 404 없음/타인 항목, 409 키 충돌·처리중, 412 버전 충돌, 422 입력 오류, 428 If-Match 누락, 429 요청 제한, 500 내부 오류를 사용한다. 500에서 원문 예외·SQL·토큰을 반환하지 않는다. 요청 제한은 사용자·IP를 함께 고려하며 실제 수치는 기술·운영 검토에서 정한다.

목록의 미정리 필터는 상태와 독립적이다. today 대신 서버가 반환한 달력 날짜와 explicit 필터를 사용한다. 완료 기록은 완료일 필터로, 날짜 배정 과제는 실행일 필터로 구분한다. 마감 조회 API 확장은 다음 과제 상세 기능에서 추가하며 첫 화면 마감 영역은 해당 확장 전까지 숨긴다.

## 검증

- 단위: 제목 정규화·길이, 날짜 경계·DST, 상태 판정.
- 통합: 계정 격리, 트랜잭션, 유일 제약, 키 재생, 버전 충돌, 완료 취소.
- 계약: 입력·응답·오류·헤더와 OpenAPI 일치.
- E2E: 로그인 후 입력 → 오늘 지정 → 완료 → 완료 취소.
- 운영: 저장 실패율·응답 지연·충돌 횟수만 집계. 본문·검색어·토큰 제외.

명세 구조 검사는 문서·JSON 연결을 확인한다. 제품 API는 OpenAPI 0.4.0 스키마로 응답 계약을 검증하며 PostgreSQL 18에서 동시 요청·롤백·복원을 시험한다. PC·모바일 제품 E2E와 자동 접근성 검사를 추가했다. 실제 Google·운영 부하 검증과는 구분한다. 최신 결과는 docs/verification/planner-core.md와 traceability.md를 따른다. 실제 CI는 `.github/workflows/verify.yml`이다.

## 배포 진입 조건

기술 선정, Google OAuth 환경 설정, D-01 가입 범위 결정, 마이그레이션·백업 복원, 핵심 수용 시나리오 검증이 필요하다. 공개 저장소 생성이나 이 설계 초안 작성으로 배포 승인을 간주하지 않는다.
