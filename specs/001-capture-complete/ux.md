# 과제 입력과 완료 화면 흐름

상태: 화면 구현·검수 기준

## 날짜별 다이어리 화면 (2026-11-07)

넓은 화면은 월간 달력·책갈피와 펼친 두 페이지로 구성한다. 왼쪽 페이지는 날짜·하루 계획·완료 기록, 오른쪽은 빠른 입력·입력함·이전 미완료다. 620px 이하에서는 페이지가 세로로 이어지고 1100px 이하에서는 달력 보기로 탐색한다. 상단 빠른 입력은 입력 필드로, 수정 버튼은 편집 제목으로 포커스를 이동한다.

- 월 탐색은 표시 월만 바꾼다. 날짜 선택·이전 날·다음 날은 해당 날짜 기록을 조회한다. 오늘로 돌아가면 계정 시간대의 오늘을 따른다.
- 입력함과 미저장 빠른 입력은 날짜 이동에도 유지한다. 오늘은 `오늘로`, 다른 날짜는 `이날로` 실행일을 배정하고 정리 완료한다.
- 완료 기록은 실제 완료 시각의 날짜에 남는다. 과거·미래 페이지에서 완료하면 실제 완료일을 안내한다.
- 날짜 변경 시 목록·커서를 비운다. 이전 날짜의 지연 응답은 최신 목록·상태를 덮지 않는다. 저장·복구 대기·수정 중에는 날짜 이동을 제한한다.
- 기존 API·인증·계정 분리를 유지한다. 자유 형식 일기와 시간 단위 일정은 이번 화면 변경에 포함하지 않는다.

## 우선순위와 다이어리 기호 (2026-11-07)

빠른 입력은 제목과 함께 유형·우선순위를 선택한다. 기본 선택은 `□ 할 일`과 `중`이다. 목록의 각 항목에는 우선순위 상·중·하 표식과 선택 메뉴를 제공하며 수정 패널에서도 같은 값을 편집한다. 저장값 high·medium·low는 각각 상·중·하다.

| 항목 유형·실행 상태 | 표시 |
|---|---|
| 미완료(open) 할 일(task) | □ 할 일 |
| 미완료(open) 약속(appointment) | △ 약속 |
| 미완료(open) 행사(event) | ○ 행사 |
| 완료(completed) | ✓ 완료 |
| 미룸(deferred) | → 미룸 |
| 취소(canceled) | × 취소 |

목록과 수정 패널의 미완료 선택지는 현재 유형의 기호를 사용한다. 완료·미룸·취소 표시는 원래 유형을 변경하지 않으며 항목 설명에 유형을 함께 제공한다. 기호 안내는 화면에 표시하고 기호·우선순위에는 텍스트 또는 접근 가능한 이름을 제공하여 색이나 모양만으로 구분하지 않는다.

미룸을 선택하면 `→`를 표시하고 실행 예정일을 유지한다. 날짜 이동은 수정 패널의 실행 예정일에서 수행하도록 안내한다. 취소는 실행일의 하루 계획에 `×`로 남고 이전 미완료에서는 빠진다. `취소 되돌리기` 또는 미완료 선택으로 원래 유형 기호를 복원한다. 완료 취소와 취소 상태를 서로 구별한다.

날짜 없는 비완료 항목에는 `정리 완료`를 제공하지 않는다. 날짜 없는 완료 항목을 미완료·미룸·취소로 변경하거나 비완료 항목의 실행일을 지우면 입력함에 유지·복귀시켜 다시 수정할 수 있게 한다. 직접 API로 이 조건에서 정리 완료를 요청하면 422로 거절한다.

수정 패널이 열려 있는 동안 목록의 우선순위·상태·완료·정리·다른 수정 버튼, 빠른 입력 저장, 시간대 저장과 날짜 탐색은 잠근다. 현재 패널의 필드·변경 저장·수정 닫기는 계속 사용할 수 있다. 저장 성공을 확인한 뒤 편집을 닫으며 실패·충돌 시 입력을 보존한다. 로그아웃·테스트 나가기는 기존의 미저장 입력 확인을 따른다.

## 화면과 이동

로그인 → 오늘 화면으로 진입한다. 최초 목표 설정을 요구하지 않는다. Google 로그인 취소·공급자 오류 시 로그인 화면에 머물고 재시도 경로를 제공한다.

오늘 화면에는 기준 날짜·시간대, 빠른 입력, 오늘 실행 과제, 이전 미완료, 오늘 마감, 오늘 완료 영역을 둔다. 입력함으로 이동할 수 있다. 일정·목표·통계의 빈 메뉴는 첫 기능에서 노출하지 않는다.

```text
오늘 2026-11-06        시간대 Asia/Seoul    입력함
[할 일 제목                                      ] [저장]
  실행 예정일: [지정 안 함 / 오늘 / 날짜 선택]
  저장 중 · 저장 완료 · 저장 실패 상태 표시

오늘 할 일       [ ] 제안서 초안
이전 미완료      [ ] 회의 자료 정리       [오늘로]
오늘 마감        실행일과 마감일의 차이를 표시
오늘 완료        [✓] 초안 검토            [완료 취소]
```

제목만 저장하면 입력함에 나타난다. 실행 예정일 오늘을 선택해 저장하면 오늘 목록에도 나타나며 같은 원본을 사용한다. 날짜 배정만으로 입력함 정리 여부를 바꾸지 않는다. 입력함에는 개별 정리 완료·되돌리기를 제공하되 전체 컬렉션 기능을 포함하지 않는다.

## 상태별 동작

| 상태 | 표시와 행동 |
|---|---|
| 초기 조회 | 로딩 상태 후 목록 표시. 실패 시 빈 목록이라고 표시하지 않음 |
| 빈 목록 | 아직 과제가 없다는 안내와 입력 동작 |
| 저장 중 | 제출 버튼 중복 실행 제한, 현재 입력과 동일 요청 키 유지 |
| 저장 성공 | 서버 확인 후 입력 초기화, 접근성 상태 메시지 제공 |
| 응답 불확실 | 입력 유지, 동일 키로 재시도, 불확실 요청을 새 키로 재생성하지 않음 |
| 제목 오류 | 입력 옆 이유 표시, 서버 오류도 같은 위치에 연결 |
| 완료 처리 | 저장 확인 후 활성 영역에서 완료 영역으로 이동 |
| 수정 충돌 | 최신 항목과 현재 편집 내용을 표시. 다시 반영 또는 최신 버전 사용 선택 |
| 세션 만료 | 재로그인 안내. 미저장 입력은 현재 탭 메모리에만 유지 |
| 계정 변경 | 다른 사용자로 바뀌면 이전 입력과 캐시를 폐기. 같은 사용자 재인증 때만 확인 후 복원 |

완료·날짜 변경을 저장 전에 성공으로 확정하지 않는다. 여러 화면의 캐시는 서버 저장 후 무효화·재조회한다. 재시도 응답이 오래된 스냅샷일 수 있으므로 재생 응답 후 최신 원본을 확인한다.

## 접근성과 모바일

가로 360px에서 한 열을 사용한다. 제목·날짜·버튼에 명시적 라벨을 제공하고 키보드만으로 저장·완료·취소를 수행할 수 있게 한다. 오류와 저장 결과는 색 외에 텍스트와 상태 알림으로 제공한다. 필수 행동을 드래그·호버에 의존하지 않는다.

## 검토 항목

이 문서는 와이어프레임의 정보 구조다. 실제 픽셀 디자인, 터치 타깃, 포커스 이동과 스크린리더 결과는 구현·UX 검토에서 확인한다. 기본 정렬은 미완료의 생성 시각 오름차순, 완료는 완료 시각 내림차순이며 ID로 동률을 정렬한다.

## 로그인 중지 중 로컬 체험 경로 (2026-11-07)

사용자가 Google 로그인 없이 화면을 테스트할 수 있도록 개발 환경에서 명시적으로 켠 `/demo` 진입을 제공한다. 로그인 화면의 활성 `로그인 없이 테스트하기` 링크로 같은 플래너 UI에 진입하며 입력·수정·실행일·완료·완료 취소·시간대 변경을 수행한다. 저장 위치는 브라우저 탭의 sessionStorage로 표시하고 새로고침 후 복원한다. 저장소 접근·저장 실패는 성공으로 표시하지 않는다.

실제 API·인증 쿠키·DB와 연결하지 않으며 계정 자료로 이전하지 않는다. 운영 빌드는 항상 404이고 개발 환경에서도 로그인 중지와 명시적 데모 설정이 모두 필요하다. Google OAuth 및 실제 서버 저장 검수는 별도로 유지한다.

기존 v1 체험 기록은 같은 저장 키로 읽으며 누락된 우선순위·유형을 `중`·`할 일`로 보충한다. 읽기만으로 저장 원문을 덮어쓰지 않고 성공한 변경에서 새 스키마로 저장한다. 제목·날짜·완료 상태·원본 ID를 유지하며 저장 실패나 잘못된 저장 자료를 빈 기록으로 덮어쓰지 않는다.
